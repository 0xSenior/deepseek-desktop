Analyzing Terrorist Attack Patterns in Egypt

Using Machine Learning & Data Mining Techniques — Graduation Project Proposal 2026

Background & Significance

Given the security challenges Egypt faces in countering terrorism, it has become essential to leverage Data Science and Artificial Intelligence tools to analyze and understand terrorist attack patterns. This project aims to transform historical terrorist attack data into actionable strategic insights.

Track Evolution

Monitor how terrorist tactics and methods evolve over time.

Identify Hotspots

Discover the most active geographical regions for attacks.

Hidden Relationships

Uncover connections between weapons, targets, regions, and outcomes.

Predictive Models

Build AI models to support strategic planning and decision-making.

Project Objectives

#ObjectiveDescription
1Exploratory Data AnalysisStudy historical data and extract initial patterns and trends.
2Association Rule MiningDiscover rules like: "If attack type is Bombing, then target is most likely Police."
3Classification ModelingPredict the terrorist group responsible for an attack.
4Spatial PredictionUse LSTM networks to forecast future attack coordinates.
5Interactive DashboardVisualize results dynamically on a map of Egypt.
